# Yomu

[日本語](README.ja.md)

A desktop Markdown reader with Japanese typography. Double-click a `.md` file to read it with the same typesetting as the [Yomu](https://github.com/shou6/yomu) VS Code extension.

> [!NOTE]
> Yomu is under development. The first release will be v1.0.0.

## Development

Requirements: Node.js 24, Rust (stable), and the [Tauri prerequisites](https://tauri.app/start/prerequisites/) for your OS.

```bash
npm install
npm run tauri dev     # Start the app for development
npm run check         # Format, lint, type check, tests, build, and version check
npm run tauri build   # Build the installer
```
